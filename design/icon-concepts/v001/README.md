# 2D to 3D icon concepts — v001

Review-only concepts. None is wired into the application or packaging configuration.

- **A — Folding plane:** a picture plane continuously folds into a cube.
- **B — Layered depth:** stacked 2D sheets rise into a voxel volume.
- **C — Pixels to solid:** a flat pixel grid resolves into a solid cube.
- **D — Frame breakthrough:** a cube emerges through a flat picture frame.

Shared art direction: dark charcoal rounded-square tile, warm orange and cream geometry, no text, and a silhouette intended to remain readable at small Windows icon sizes.

Generation mode: built-in image generation.
